// PLATFORM FEATURES

平台核心特色

🎯
自适应学生水平

系统结合历史正确率、练习次数和词汇 XP 持续更新能力等级，并自动发放基础、标准或进阶难度；同一词包的难度内容生成一次即可重复使用。

🗺️
故事化 RPG 学习地图

每个词包拥有专属世界、主角和剧情支线。每关最多 10 个词，章节数量随词包自动拆分；词汇闯关和句子填空共享连续冒险体验。

📊
可导出的学习报告

班级周报、学期对比、高频错词 Top 20、词汇难度分布和学生个人档案一站生成，相同数据直接调用缓存，并可导出带 VocaQuest 标识的 PDF。

🏆
成就、XP 与排行榜

两个学习工具统一累计 XP，并展示总榜与分工具榜。宠物、称号、徽章、Boss 和班级挑战把持续练习转化为可见成长。

🔐
安全邀请码与班级管理

学生单次邀请码使用后立即失效；班级邀请码会自动加入指定班级。班级选择一经确认不可更改，每班最多 60 人。

🧠
教师内容一次生成

老师上传词包后生成故事、美术与三档语境练习，后续学生共享缓存内容，减少重复调用和教师备课时间。

// HOW IT WORKS

3 步开始学习

01
获取邀请码

从老师处获取一次性学生邀请码或班级邀请码。班级邀请码会自动加入对应班级，一次性邀请码使用后立即失效。

02
注册账号，进入 Dashboard

输入姓名、邮箱、密码与邀请码完成注册。使用单次邀请码的学生可在 Dashboard 自行选择一次班级，确认后不可更改。

03
选择工具，开始练习！

点击任意工具卡片进入练习。老师已分配任务的工具会优先显示，完成任务积累 XP，冲上总排行榜。
